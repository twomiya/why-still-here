# 《你为什么还没辞职？》静态网页原型

## 打开与部署

- 本地体验：直接用浏览器打开 `index.html`。
- 发布：将 `index.html` 放到支持 HTTPS 的静态网站托管服务。页面没有后端依赖，也不需要数据库或 API 密钥。
- 发布后务必亲自用手机走完整个流程，检查分享文案中的公开链接，以及分享图片的下载效果。
- 未发布前分享图会明确标明“本地原型 · 尚无可访问的测试链接”。不要把本地文件路径当作可分享网址。

## 隐私边界

- 答案只在页面运行期间留在浏览器内存；刷新即清空。页面代码没有提交答题数据的网络请求，也没有本地存储逻辑。
- 分享图和分享文案不包含原始答题记录。可选反馈由用户自行复制，不会自动发送。
- **托管平台仍可能记录页面访问日志**；若要正式发布，应检查托管方的日志、隐私设置、域名和任何额外加入的统计脚本。不要在未核对部署环境前宣称整个站点“零数据收集”。
- 题目涉及工作、经济及家庭处境；避免添加未经用户明确同意的自动分析或埋点。

## 原型的能力与限制

- 功能：15 题逐题作答、返回修改、六类可能结果、显示判断依据、分享文案、PNG 分享图、可选试答反馈。
- 评分阈值是原型参数，尚未经过真实用户验证。这是帮助自我梳理的内容，不是心理诊断、职业建议或“应该辞职”的判断。
- 测试脚本 `test_prototype.py` 留在源目录，需本地 Chrome、Python Playwright 和一个在 127.0.0.1:8765 提供本目录的静态服务；交付包包含网页及两份说明文档。

## 发布前检查

1. 在手机和桌面浏览器上，从首页答到结果，并尝试返回修改与重新开始。
2. 选几组边界答案：现实阻力明显；没有唯一倾向；关键现实题选“不想回答”。确认不会硬贴标签。
3. 下载分享图并检查文字没有截断、没有敏感答案。
4. 在真正的公开 HTTPS 地址上测试分享文案；确认链接指向测试首页且可由另一台设备访问。
5. 用 `PILOT.md` 的方案组织真实试答，先改误判，再考虑正式推广。
